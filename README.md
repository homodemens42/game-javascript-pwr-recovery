# game-javascript-pwr-recovery

PWR（加圧水型原子炉）を題材にした、ターミナル操作型の復旧ゲームです。

現在はプレリリース版です。

## 遊び方

ターミナルからコマンドを入力してプラントの状態を調査し、異常の原因を特定してください。

```text
STATUS
STATUS PRIMARY
READ RCP-A
ALARM
```

必要に応じて設備を操作します。

```text
CONTROL REACTOR TRIP
CONTROL RCP-A STOP
```

使用できるコマンドや設備については、ゲーム画面右側のマニュアルを参照してください。

## 目的

単に異常箇所を見つけるだけではなく、**プラントを安全側へ収束させること**が目的です。

AUTOによる保護動作が発生することもありますが、自動的にすべての異常が解決するとは限りません。

## 収録内容

現在は10ステージ＋チュートリアル＋シミュレーションモードを収録しています。

一次冷却系、給水系、復水器、非常用電源、補助給水、計装、一次系漏えい、補機冷却系など、ステージごとに異なる異常が発生します。

チュートリアルでは、ターミナル操作・マニュアル参照・設備調査の基本的な流れを確認できます。

シミュレーションモードでは、正常運転中のプラントに対して各種コマンドを自由に試し、設備状態やAUTO／INTERLOCKの挙動を確認できます。

## 動作環境

HTML / CSS / JavaScriptで動作します。

インストール不要で、PCブラウザからそのままプレイできます。
