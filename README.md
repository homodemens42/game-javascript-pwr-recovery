# game-javascript-pwr-recovery

PWR（加圧水型原子炉）を題材にした、ターミナル操作型の復旧ゲームです。

現在はプレリリース版です。

遊び方

ターミナルからコマンドを入力してプラントの状態を調査し、異常の原因を特定してください。

STATUS
STATUS PRIMARY
READ RCP-A
ALARM

必要に応じて設備を操作します。

CONTROL REACTOR TRIP
CONTROL RCP-A STOP

使用できるコマンドや設備については、ゲーム画面右側のマニュアルを参照してください。

目的

単に異常箇所を見つけるだけではなく、プラントを安全側へ収束させることが目的です。

AUTOによる保護動作が発生することもありますが、自動的にすべての異常が解決するとは限りません。

収録内容

現在8ステージを収録しています。

一次冷却系、給水系、復水器、非常用電源、補助給水、計装など、ステージごとに異なる異常が発生します。

動作環境

HTML / CSS / JavaScriptで動作します。

インストール不要で、PCブラウザからそのままプレイできます。

Version

v0.4.0-pre.2

開発中のプレリリース版です。
不具合や挙動についてのフィードバック歓迎です。

注意

本作はゲームとして簡略化されたシミュレーションです。

実際の原子力発電所の設備・運転手順・設定値などを正確に再現することを目的としたものではありません。
